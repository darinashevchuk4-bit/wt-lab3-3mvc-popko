# wt-lab3-3mvc-popko

Лабораторная работа WT-3 «Реализация MVC-архитектуры в консольном приложении C#».
Дисциплина «Web-технологии», вариант 13 — **Музыкальный сервис** (сущность `Track`).

Выполнила: Попко Д.А., группа 1д2401ГУП.

## Структура
```
Models/Track.cs                    — модель (данные трека)
Views/TrackView.cs                 — представление (вывод в консоль)
Controllers/TrackController.cs     — контроллер (команды, поиск, добавление, удаление)
Program.cs                         — точка входа: создаёт контроллер и запускает меню
```

## Запуск
```
dotnet run            # меню
dotnet run -- demo    # демонстрация последовательности Index/Show/Add/Delete
```
